# GloveHost Project Structure

This document explains the organization of the GloveHost C++ codebase.

---

## 📁 Root Directory

```
C++/
├── Source/              # All source code
├── Assets/              # Resources (models, presets, sounds, VSTs)
├── build/               # Build output (generated by CMake)
├── CMakeLists.txt       # Build configuration
├── README.md            # Project overview
├── INSTALLATION_GUIDE.md # Setup instructions
└── PROJECT_STRUCTURE.md  # This file
```

---

## 📂 Source/ Directory

Contains all C++ implementation files organized by functionality:

```
Source/
├── main.cpp             # Entry point, main controller
│
├── Audio/               # JUCE audio engine and audio processing
│   ├── JuceAudioEngine.cpp/h    # Main audio engine
│   ├── AudioTrack.h             # Track management (VST/Samples/MP3)
│   ├── MidiRouter.h             # Lock-free MIDI routing
│   ├── LoopRecorder.h           # Loop recording system
│   ├── PauseController.h        # Pause/resume control
│   ├── SamplePlayer.h           # Drum sample playback
│   └── AudioConfig.h            # Audio configuration structs
│
├── Instruments/         # Instrument controllers
│   ├── Drums/
│   │   ├── DrumFlexController.cpp/h    # Flex-based drum triggering
│   │   └── DrumZonesController.cpp/h   # Zone-based drum triggering
│   │
│   ├── Guitar/
│   │   └── GuitarController.cpp/h      # Guitar with AI strum detection
│   │
│   ├── Keys/
│   │   ├── KeysController.cpp/h        # Single note keyboard
│   │   └── ChordsController.cpp/h      # Chord detection
│   │
│   └── Violin/
│       └── ViolinController.cpp/h      # Violin with AI bow detection
│
├── Looping/             # Gesture-based loop control
│   └── loop.cpp/h       # Wakanda gesture, L-pose detection
│
└── core/                # Core system components
    ├── main_controller.h        # System orchestration
    ├── SensorSample.h           # Sensor data structures
    └── InstrumentController.h   # Base instrument interface
```

## 📂 build/ Directory

**Generated by CMake** - do not manually edit:

```
build/
├── Release/             # Release build output
│   ├── GloveHost.exe    # Main executable
│   ├── config.json      # Runtime configuration
│   └── *.dll            # Required DLLs (TensorFlow Lite, etc.)
│
├── Debug/               # Debug build output (optional)
├── CMakeFiles/          # CMake internal files
└── *.sln, *.vcxproj     # Visual Studio project files
```

---

## 🔧 Key Files

### CMakeLists.txt
Build configuration for the entire project. Defines:
- Source files to compile
- JUCE modules to link
- TensorFlow Lite integration
- Compiler flags and definitions

### config.json
Runtime configuration (created in `build/Release/`):
- Audio device settings (sample rate, buffer size, ASIO)
- Track definitions (VST paths, presets)
- Drum sample mappings

---

## 🚀 Build Output

After building, the executable and required files are in:
```
build/Release/
├── GloveHost.exe           # Main application
├── tensorflowlite.dll      # AI inference library
└── config.json             # Configuration file
```

## 📝 Adding New Instruments

To add a new instrument:

1. **Create controller files** in `Source/Instruments/YourInstrument/`
   ```cpp
   YourInstrumentController.h
   YourInstrumentController.cpp
   ```

2. **Add to CMakeLists.txt**
   ```cmake
   Source/Instruments/YourInstrument/YourInstrumentController.cpp
   ```

3. **Register in InstrumentManager** (`Source/main.cpp`)
   ```cpp
   instruments_[INSTRUMENT_YOUR_ID][mode] = 
       std::make_unique<YourInstrumentController>();
   ```

4. **Rebuild**
   ```bash
   cmake --build build --config Release
   ```

## 🎯 Dependencies

### Required
- **JUCE 7.x** - Audio framework (`C:\JUCE`)
- **TensorFlow Lite** - AI inference (`C:\TensorFlowLite`)
- **CMake 4.2+** - Build system
- **Visual Studio 2022** - C++ compiler

### Optional
- **VST Plugins** - For instrument sounds
- **ASIO Driver** - For low-latency audio
